# FertiBase — Website User Manual & Documentation

## Executive Summary

**FertiBase** is a responsive agricultural website platform designed to connect farmers with high-quality fertilizer products, valuable resources, company career opportunities, and company information. The website provides an intuitive interface for browsing products, accessing educational resources, learning about the company, and reaching out for business inquiries.

- **Target Audience:** Farmers, agronomists, agricultural retailers, job applicants, and content administrators.
- **Supported Browsers:** Chrome, Edge, Firefox, Safari (latest versions, desktop & mobile).
- **Design:** Fully responsive (mobile-first approach).

## Content Management Guide

### Managing Products

**File:** `src/data/productsData.js` or `data/productsData.js`

**To add/edit products:**
1. Edit the products data file
2. Add new product object with fields:
   - `id` — unique identifier
   - `name` — product name
   - `category` — one of: All, Biofertilizer, Organic Biofertilizer, Liquid Fertilizer, Straight Micronutrient, Beneficial Element Fertilizer
   - `description` — product description
   - `image` — image file path
   - `price` (optional) — product price
   - `uses` — recommended uses
   - `dosage` (optional) — application instructions
3. Run `npm run dev` to see changes

### Managing Resources

**File:** `src/lib/latestUpdates.js` or resource database

**To add/edit resources:**
1. Add resource entry with:
   - `id` — unique identifier
   - `title` — resource title
   - `category` — one of: All, Webinars, Technical Guides, Marketing Materials, Posters, PPTs
   - `subcategory` (for Marketing Materials) — Banners, Brochures, Flyers, Standees
   - `description` — brief description
   - `fileUrl` or `embedUrl` — link to download or view
   - `thumbnail` — preview image
2. Deploy changes

### Managing Announcements

**File:** `src/lib/latestUpdates.js`

**To add announcements:**
1. Add announcement object with:
   - `id` — unique identifier
   - `title` — announcement headline
   - `content` — announcement message
   - `date` — publication date
   - `priority` (optional) — display priority
2. Run `npm run dev` to preview

### Managing Career Postings

**File:** Supabase database or `src/data` (if local)

**To add job postings:**
1. Access career data source (Supabase dashboard or local file)
2. Add job record with:
   - `id` — unique job ID
   - `title` — job title
   - `department` — department/team
   - `location` — office location
   - `jobType` — Full-time, Part-time, Contract
   - `description` — full job description
   - `requirements` — required qualifications
   - `benefits` — job benefits
3. Sync with frontend by rebuilding

### Managing Images & Assets

**File:** `src/config/images.js`

**To update images:**
1. Place image files in `public/posters/` or `src/assets/`
2. Update `images.js` with file paths
3. Reference image keys in components
4. Rebuild and deploy

## Forms & Data Submission

### Contact Form

**Fields:**
- Name (required, text)
- Email (required, email validation)
- Phone (optional, text)
- Subject (required, text)
- Message (required, textarea)

**Submission target:** Configured endpoint in `src/api/api.js` or Supabase table

**Client-side validation:** Name, email, message must be non-empty

**Server-side validation:** Required (implement in backend)

### Job Application Form (ApplyForm)

**Fields:**
- Full Name (required, text)
- Email (required, email validation)
- Phone (required, text)
- Position Applied For (required, dropdown/text)
- Experience (required, textarea)
- CV/Resume (required, file upload)
- Cover Letter (optional, textarea)

**Submission target:** `src/api/careerService.js` endpoint or Supabase table

**Client-side validation:** All required fields must be filled; file size limits enforced

**Server-side validation:** Required (implement in backend)

## API & Integration Reference

### Supabase Configuration

**Client setup file:** `src/api/supabaseClient.js`

**Environment variables required:**
- `VITE_SUPABASE_URL` — Supabase project URL
- `VITE_SUPABASE_KEY` — Supabase anon key

**Tables expected:**
- `products` — product catalog
- `careers` — job postings
- `testimonials` — farmer stories
- `resources` — educational materials
- `contacts` — submitted contact form data
- `applications` — job application submissions

### API Service Modules

**File:** `src/api/productService.js`
- `fetchProducts()` — Get all products
- `fetchProductById(id)` — Get single product
- `searchProducts(query)` — Search by name/description

**File:** `src/api/careerService.js`
- `fetchCareers()` — Get all job listings
- `fetchCareerById(id)` — Get job details
- `submitApplication(formData)` — Submit application

**File:** `src/api/testimonialService.js`
- `fetchTestimonials()` — Get farmer stories
- `fetchTestimonialsByCategory(category)` — Filter stories

**File:** `src/api/api.js`
- `submitContactForm(formData)` — Submit contact request
- Generic HTTP request utilities

## Security & Best Practices

**Do's:**
- Keep `.env` file local (never commit secrets)
- Use environment variables for all sensitive config
- Implement server-side form validation
- Use HTTPS for all connections
- Sanitize user inputs
- Implement rate limiting on backend

**Don'ts:**
- Commit `.env` file to version control
- Expose API keys in frontend code
- Trust client-side validation only
- Store sensitive data in localStorage without encryption
- Hardcode secrets

## Troubleshooting Guide

| Issue | Solution |
|-------|----------|
| Dev server won't start | Run `npm install` then `npm run dev`; check for port conflicts or missing env vars |
| Products not displaying | Verify `productsData.js` is populated; check browser console for errors |
| Forms not submitting | Check `.env` Supabase config; inspect Network tab for failed requests; verify backend endpoints |
| Images not loading | Confirm file paths in `config/images.js`; check `public/` and `src/assets/` directories |
| Build fails | Run `npm install` to ensure dependencies; check for syntax errors in components |
| Styling issues | Clear browser cache; rebuild Tailwind CSS with `npm run build` |

## FAQ

**Q: How do I add a new product category?**
- A: Edit the category filter list in `ProductsPage.jsx` and update `productsData.js` with new category values.

**Q: Can I change the navbar links?**
- A: Yes, edit `src/components/Navbar.jsx` to add/remove navigation links and routes.

**Q: How are farmer stories displayed?**
- A: Testimonials are fetched via `testimonialService.js` and displayed in `FarmerStories.jsx` component.

**Q: Can I host the site on my own server?**
- A: Yes, build with `npm run build` and serve the `dist/` folder using any static web server (Apache, Nginx, etc.).

**Q: How do I update business hours on the Contact page?**
- A: Edit the hours data in `Contact.jsx` component directly or move to a data file for easier management.
